import LineChart from "../../components/LineChart.astro";

This post embeds an interactive chart. The surrounding text is still static
HTML; only the chart below ships JavaScript to your browser.

## Monthly readers (made-up data)

<LineChart
  label="Readers"
  labels={["Jan", "Feb", "Mar", "Apr", "May", "Jun"]}
  data={[12, 19, 14, 23, 28, 31]}
/>

The chart above is a reusable component. To add another one to a different
post, import it and pass different data. Nothing else on the page pays the
cost of that JavaScript.

## How it works

The component is an Astro "island". At build time the page is rendered to
static HTML, and the chart's code is bundled separately so it only loads here.
This is the pattern you'll reuse for maps and other interactive elements.
